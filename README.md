# Raíces Cancún 🏛️🌴

Aplicación móvil híbrida desarrollada para la exploración, ubicación e información histórica de zonas arqueológicas en la Península de Yucatán.

## 🚀 Stack Tecnológico
- **Frontend:** React 19 + Vite
- **UI:** Ionic Framework 9 (Componentes Nativos)
- **Nativo:** Capacitor 8 (Geolocalización, Intents de Google Maps)
- **Backend/Base de Datos:** Supabase (En progreso)

## 🛠️ Instalación y Uso Local
1. Clonar el repositorio: `git clone <URL_DEL_REPOSITORIO>`
2. Instalar dependencias: `npm install`
3. Levantar el entorno de desarrollo web: `npm run dev`
4. Compilar e instalar en Android (requiere Android Studio y SDK configurado en `local.properties`):
   - `npm run build`
   - `npx cap sync android`
   - `npx cap run android`
